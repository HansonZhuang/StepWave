# 蜡烛图与量价分析 · 核心框架笔记

> 原创归纳的公开技术分析概念框架, 非任何书籍摘录。K线形态与量价关系是缠论/波浪之外的第三类独立证据,
> 用于在结构关键位上做"确认/否决"。

## 一、使用前提: 位置重于形态

- 同一形态在不同位置含义完全不同: **看跌反转形态只在高位/阻力位有效, 看涨反转形态只在低位/支撑位有效**。
- 本项目的用法: 在中枢上下沿、斐波那契位、观察窗内出现对应形态, 才算确认信号的一部分; 半山腰的形态不具备操作含义。

## 二、常用单根/组合形态(反转类)

| 形态 | 结构特征 | 有效位置 |
|---|---|---|
| 锤子线 | 小实体 + 长下影(≥2倍实体), 出现在下跌末端 | 低位支撑区 |
| 上吊线 | 同锤子线形态, 但出现在上涨末端 | 高位阻力区 |
| 看涨吞没 | 阳线实体完全包住前一根阴线实体 | 低位 |
| 看跌吞没 | 阴线实体完全包住前一根阳线实体 | 高位 |
| 启明星 | 大阴 + 跳空小实体 + 大阳(收复阴线一半以上) | 低位, 三根组合 |
| 黄昏星 | 大阳 + 跳空小实体 + 大阴 | 高位, 三根组合 |
| 乌云盖顶 | 阴线开于前阳线最高价上方, 收于其实体一半以下 | 高位 |
| 刺透形态 | 乌云盖顶的镜像(阳线深入前阴线实体一半以上) | 低位 |
| 十字星 | 开收几乎相同, 多空平衡 | 趋势末端出现才有转折暗示 |

持续类(窗口/跳空、三法等)含义: 趋势中继, 缺口方向即趋势方向; 向上跳空缺口回补不破可视为支撑。

## 三、量价关系八字诀

| 量价组合 | 解读 |
|---|---|
| 放量上涨 | 趋势健康(但高位巨量滞涨=出货嫌疑) |
| 缩量上涨 | 上攻乏力, 新高无量警惕顶背离 |
| 放量下跌 | 恐慌或主动出逃, 下跌有效性高 |
| 缩量下跌 | 抛压衰竭, 配合低位形态可关注 |
| 放量突破关键位 | 突破可信度高(本项目: 突破中枢上沿必须放量) |
| 缩量回踩不破 | 洗盘特征, 支撑有效 |
| 天量见天价 | 极端放量常伴随阶段顶 |
| 地量见地价 | 极端缩量常先于阶段底(但需形态确认) |

## 四、与本项目体系的衔接

1. 缠论给出**位置**(中枢上下沿/三类买卖点), 波浪给出**目标**(斐波位), 蜡烛图+量价给出**当下确认**。
2. 谷底观察窗(板块⑦)的确认信号明确要求: 窗内 背驰 或 底分型+缩量——"底分型"即缠论化的低位反转组合, "缩量"即抛压衰竭证据。
3. 建议引擎的风控先验已包含: 放量突破才可信、缩量新高警惕背离、反转形态必须结合位置。
