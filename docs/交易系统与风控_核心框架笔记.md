# 交易系统与风控 · 核心框架笔记

> 原创归纳的公开交易方法论概念, 非任何书籍摘录。技术分析解决"何时何价", 本笔记解决"多少与纪律"——
> 没有仓位管理的信号系统在实盘中不可持续。

## 一、趋势交易的经典原则(公开常识归纳)

- **顺势**: 只沿最小阻力方向交易; 趋势未确认不重仓, 趋势确认后不轻易下车。
- **关键点**: 在结构关键位(突破/回踩确认处)入场, 而不是任意位置; 入场即错(价格立刻反向)说明判断有误, 快速认错。
- **金字塔加仓**: 只给盈利的仓位加码, 且越加越少; **严禁给亏损仓位摊平**——摊平是把小错变成大错的机制。
- **止损先行**: 下单前先定止损位(本项目: 止损锚定结构位——中枢边界/前低/笔端点), 止损是成本不是损失。
- **利润奔跑**: 赚钱的单子靠"持有纪律"而不是靠预测卖点; 离场交给结构破坏信号(三卖/背驰/跌破关键位)。

## 二、头寸规模: 两个可计算的口径

### 1. 固定风险比例法(推荐默认)

```
单笔最大亏损 = 总资金 × 1%~2%
头寸股数 = 单笔最大亏损 ÷ (入场价 - 止损价)
```

止损越远, 仓位越小——仓位由止损距离反推, 而不是由"信心"决定。

### 2. 波动率调整法(海龟式思想)

```
头寸单位 = 总资金 × 1% ÷ (N × 每股波动金额)    # N≈ATR(14)
```

高波动标的自动获得更小仓位, 使不同标的的"每日账户波动贡献"大致相等。

### 3. 凯利公式(仅作仓位上限参考)

```
f* = (bp - q) / b     # p=胜率, q=1-p, b=盈亏比
```

实战取**半凯利或更低**; 胜率/盈亏比估计误差很大时, 凯利值仅用于提醒"上限", 不作为实际仓位。

## 三、组合层面的风控

| 规则 | 口径 |
|---|---|
| 单笔风险 | ≤ 总资金 2% |
| 单一标的 | ≤ 总仓位 30%(高波动小票更低) |
| 相关性敞口 | 同板块/同逻辑的持仓合并计算风险 |
| 总回撤刹车 | 账户自高点回撤 >10% 时强制降半仓复盘 |
| 连亏熔断 | 连续 3 笔止损后暂停开新仓, 先复盘再交易 |

## 四、纪律清单(接入本项目闭环)

1. 每笔建议必须带: 入场结构依据 + 止损位 + 失效条件(本项目建议引擎已强制)。
2. 执行与复盘分离: 当日按计划执行, 收盘后由复盘(板块⑥)评判计划质量, 教训进先验库。
3. 模拟盘先行: 任何策略调整先过模拟盘统计(≥20交易日), 再谈真实资金。
4. 情绪开关: 重大亏损当日不做任何新决策——这是利弗莫尔式教训的现代版。
