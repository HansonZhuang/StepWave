# stock-insight — 新闻 + 缠论/波浪结构 + LLM 研判的个人股票分析工作台

一个自托管的 Web 应用：每天自动采集财经新闻并用 LLM 分类与影响分析，拉取 A股/港股/美股行情做缠论（分型/笔/中枢/三类买卖点/背驰）与艾略特波浪结构分析，生成当日操作建议与持仓方案，收盘后自动复盘"执行建议 vs 持有不动"的盈亏差并把教训沉淀为先验知识，形成**建议 → 复盘 → 教训 → 改进建议**的闭环。

> ⚠️ 免责声明：本项目所有输出均为"结构化技术信号 + 大模型研判"，仅供学习与研究参考，**不构成任何投资建议**。股市有风险，决策请独立判断。

## 功能一览（网站六大板块）

| 板块 | 功能 |
|---|---|
| ① 今日要闻 | 新闻自动分 7 类，每类置顶 2-3 条带重要性评级与"对股票的影响"一句话；点击看详情；关键词搜索 |
| ② 走势展示 | 关注列表 K 线：蓝框=缠论中枢、金线=笔、标记=三类买卖点信号；现价约 30 秒轮询刷新 |
| ③ 当日买卖点位 | 关注列表每只的动作/仓位/挂单价/止损，点位锚定中枢上下沿与斐波那契位 |
| ④ 总体研判 + 个股查询 | 上证+纳指结构 + 新闻情绪 → 总仓位建议；输入任意代码即时分析 |
| ⑤ 持仓顾问 | 录入 市场+代码+股数(+成本) → 卖多少/留多少 + 挂单价 + 加仓价/清仓触发价（含 A 股/北交所交易规则约束） |
| ⑥ 收盘复盘 | 按限价成交规则模拟当日挂单，对比"执行建议 vs 持有不动"盈亏；建议更差时 LLM 自动总结教训写入先验库 |
| ⑦ 谷底观察窗 + 模拟盘 | 三个确定性计算量（本股历史下跌笔持续分位 / 斐波那契时间窗 / ABC时间比例）框出"底部信号密集的时间范围"+价格底候选；模拟盘把每日建议在虚拟账户自动成交，累计净值 vs 持有不动，给出"是否值得实盘"的统计证据 |

## 快速开始

```bash
# 1. 环境 (推荐 uv)
uv venv .venv --python 3.11
uv pip install -p .venv -r requirements.txt

# 2. 配置 LLM 接入 (Anthropic API 或任何兼容 /v1/messages 的代理)
cp .env.example .env   # 按需修改后 source .env, 或直接 export
cp knowledge/lessons.example.md knowledge/lessons.md

# 3. 启动
cd webapp && ../.venv/bin/python app.py   # 默认 0.0.0.0:8688
```

浏览器打开 `http://localhost:8688`。部署在远程服务器时用 SSH 端口转发或 VS Code 端口面板访问。

## 架构与数据源

```
新闻(财联社/新浪/东财) ─→ news_service ─ LLM分类/影响 ─┐
行情(东财→新浪→腾讯 三源容错) ─→ chan_analyzer 结构 ─┼→ advisor/portfolio (LLM) → 建议
指数(上证/纳指) ───────────────────────────────┘        ↓
实时报价(新浪+腾讯, 秒级快照) → 前端轮询         evaluator 收盘复盘 → lessons.md 先验 ─(注入提示词)→ 下次建议
```

| 数据 | 来源与容错 |
|---|---|
| A股日线 | 东方财富(前复权) → 新浪(前复权; 北交所走K线JSON, 未复权) → 腾讯；单源故障自动切换 |
| 港股/美股日线 | 新浪(前复权) |
| 实时报价 | 新浪 hq 接口(沪深/港/美/指数) + 腾讯(北交所)；当日K线缺失时由报价合成 |
| 新闻 | 财联社电报 + 新浪全球财经 + 东财个股新闻，哈希去重按天落盘 |
| LLM | 环境变量配置：`LLM_FAST_MODEL` 批量新闻分类，`LLM_SMART_MODEL` 个股/大盘/持仓/教训等重判断 |

所有行情与新闻均来自公开免费接口，请控制调用频率、遵守各数据源的使用条款，仅作个人研究使用。

## LLM 提示词位置

全部内嵌在各服务模块中（输出均要求严格 JSON、点位必须锚定结构位、语气克制）：

| 位置 | 用途 |
|---|---|
| `news_service.py: CLASSIFY_SYSTEM / SUMMARY_SYSTEM` | 新闻分类与影响 / 当日大势研判 |
| `advisor.py: STOCK_SYSTEM / OVERVIEW_SYSTEM` | 个股建议 / 大盘总研判（注入 lessons 先验） |
| `portfolio.py: HOLD_SYSTEM_TPL` | 持仓操作方案，含交易规则约束（注入 lessons 先验） |
| `evaluator.py: LESSON_SYSTEM` | 复盘劣于基准时总结教训 |

## 内建定时器

容器/无 cron 环境下由 `app.py` 内置线程完成（依赖服务进程存活）：工作日 9:36–11:30 窗口自动生成持仓方案（当日已有则复用）；15:07 后自动生成复盘报告 + 模拟盘结算（已存在则跳过）。有 cron 的环境也可直接定时跑 `morning_advise.py` / `evaluator.py` / `paper_trader.py`。

## 模拟盘与实盘边界

本项目**不做实盘自动下单**（A 股个人程序化交易有资质与合规门槛，且应先有统计证据）。路径设计为三级：

1. **模拟盘**（已实现）：建议自动在虚拟账户成交，防作弊（只执行 15:00 前生成的方案），累计净值 vs 持有不动；
2. **实盘门槛**（写死在报告里）：累计 ≥20 交易日 且 累计跑赢持有不动 且 日胜率 >50%，三条全满足才值得讨论下一步；
3. 到达门槛后推荐的半自动路径：网站产出点位 → 人工在券商 App 挂**条件单**，保留人工合规检查点。

## 关于"预测大跌/大涨时间点"

精确日期在方法论上不可得（数浪多义性、新闻只改变风险密度）。板块⑦提供的是可计算的**观察窗**：本股历史下跌笔持续天数分位（实证统计）、斐波那契时间窗、ABC 时间比例三个独立依据的交集，窗内必须等背驰/底分型确认才算底部候选成立。这是"概率密集区提示"，不是预言。

## 已知限制

- 复盘为日内口径：持仓按昨收计价、限价单触价即视为成交、未计手续费/滑点。
- 北交所在东财源限流时回落到未复权数据，除权日附近长周期结构可能失真（页面标注数据源）。
- ETF/指数暂不支持个股查询。
- "大跌/大涨时间点预测"是理论能力边界：波浪/缠论给出的是**条件化触发位**（跌破某位转空、突破某位转多），不是日期预言。
- 单日复盘样本噪音大，建议积累 20+ 交易日后看累计胜率再评估建议有效性。
